# IND Protocol

**Inheritance Dollar (IND)** is an experimental programmable custody protocol on Ethereum.

IND explores a custody model where value can be transferred, protected, delayed, revoked before finalization, and integrated with inheritance-aware ownership semantics.

Official website:

https://ind.finance

Mainnet status:

https://ind.finance/mainnet-status.html

## Core concepts

- Protected transfers
- Delayed ownership
- Revocable custody windows
- Protected and unprotected balance semantics
- Default heir configuration
- Annual balance signature
- Revoke-key based recovery controls
- ERC20 compatibility boundaries

## Current status

IND is live on Ethereum mainnet as an experimental protocol.

The repository contains smart contracts, protocol documentation, deployment notes, compatibility analysis and audit-oriented material.

## Protocol positioning

IND should not be understood as a meme token, exchange project or speculative trading interface.

It is better understood as experimental protocol infrastructure for programmable custody, delayed ownership and inheritance-aware value management.

## Mainnet warning

IND is experimental software.

Users should understand Ethereum transaction risk, key custody, revoke-key handling, protected transfer timing and wallet backup procedures before interacting with mainnet contracts.
